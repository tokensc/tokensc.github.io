TokenSC API for bot developers

The same on-chain risk checks our Telegram bot @tokensafchebot runs, as one JSON reply per Solana token mint. Use it to show red and yellow flags next to each token in your own trading, alert or group bot.

Endpoint

GET  https://tokensc.138-199-237-15.sslip.io/v1/check?mint=<token mint>

Keep your key server-side; don't ship it inside a public client.

no red flags foundwarningsred flags We never say "safe". If something can't be verified, it is reported as a red flag rather than guessed. Finding levels: ok, info, warn, red.

What is checked

Scam lists (suspected / confirmed, with source), mint and freeze authority, Token-2022 extensions (transfer fees, hooks, permanent delegate, pausable), metadata mutability, liquidity and liquidity vs market cap, recent trading behaviour, LP burned / locked, top-holder concentration and creator history. No sell simulation.

A fresh check takes about 5–20 s. Set a client timeout of at least 60 s.
